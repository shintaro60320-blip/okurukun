おくるくん プライバシーポリシー

制定日：2026年11月13日　／　提供：URUE RELATION NET

1. このポリシーの対象

Windows用アプリ「おくるくん」（以下「本アプリ」）が、利用者の情報をどのように扱うかを定めます。

2. 本アプリがアクセスするGoogleのデータ

本アプリは、利用者が許可した場合にだけ、Google ドライブの権限 https://www.googleapis.com/auth/drive.file を使います。この権限で扱えるのは、本アプリが作成したファイルとフォルダだけです。

  • 利用者が選んだファイルを、利用者本人のGoogleドライブの専用フォルダにアップロードします。
  • アップロードしたファイルに「リンクを知っている人は閲覧できる」共有設定を付けます。
  • 保存期間が来た時、または利用者が止めた時に、その共有設定を外し、ファイルをゴミ箱に移します。
  • アップロードの前に、ドライブの空き容量を確認します。

ドライブにある他のファイルの読み取り、変更、削除は行いません。

3. 利用者のパソコンに保存する情報

  • Googleへのログイン情報（Windowsの暗号化機能で保護し、同じパソコンの同じユーザーでしか読めない形で保存します）
  • 送ったファイルの名前・大きさ・ドライブ上のID・リンク・送った日時・保存期間（「送ったもの」の一覧と自動片付けに使います）
  • 動作の記録（不具合を調べるためのログ。パスワードやログイン情報は書きません）

4. 外部への送信

本アプリが通信する相手は Google（Google ドライブの公式API）だけです。開発者のサーバーへの送信、第三者への提供、販売、広告への利用は行いません。

5. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

6. 利用者が情報を消す方法

  • 送ったファイル：本アプリの「今すぐ止める」、またはGoogleドライブから直接削除できます。
  • 本アプリへの許可：Googleアカウントのサードパーティ製アプリとの接続から取り消せます。
  • パソコン内の情報：%LOCALAPPDATA%\OkuruKun フォルダを削除すると、すべて消えます。

7. 変更

このポリシーを変更する場合は、このページを更新し、制定日を書き換えます。

8. お問い合わせ

Googleのログイン画面（同意画面）に表示されるサポートメールアドレスまでご連絡ください。
